# Pizzería di Pablo - Semana 4

## Desarrollo App Móviles (PMY2201)

Aplicación móvil desarrollada en Kotlin utilizando Android Studio y Jetpack Compose.

## Funcionalidades

- Mensaje de bienvenida solicitado.
- Catálogo con cinco variedades de pizzas.
- Visualización de precios y promociones.
- Integración de las clases Kotlin de semanas anteriores.
- Simulación de pedidos utilizando Cliente, Producto y Pedido.
- Cálculo de descuentos, IVA del 19% y total.

## Configuración

- Proyecto: PizzeriaApp
- Plantilla: Empty Activity
- Lenguaje: Kotlin
- Minimum SDK: API 24
- Emulador: Pixel 4 con Android 15 (API 35)

## Ejecución

1. Abrir la carpeta PizzeriaApp en Android Studio.
2. Sincronizar Gradle.
3. Seleccionar un dispositivo Android compatible.
4. Ejecutar la configuración app.
5. Presionar Probar en alguna pizza para visualizar el resumen.

## Evidencias

Las capturas de instalación, configuración y funcionamiento están en la carpeta Evidencias.

Los pedidos demostrativos no registran ventas reales ni modifican el inventario.
